# 傻子文案大师 V0.4 · 全行业版

> **一个专门服务于傻子的工具**
> 17 个行业，什么店都能用

给实体门店**老板 / 店长 / 店员**用的抖音短视频口播生成工具。
首页选一次行业（会记住），后面还是那 7 步，流程一步没加。

核心只有一句话：**用户不会写文案，甚至不会描述需求，也没关系。**
全程点选，不给你一个空白输入框。点几下 → AI 思考 → 出成品。

不是「写一篇漂亮文案」，而是「拿起来就能拍」。

## 〇、V0.4 改了什么（架构变更，先看这段）

**问题**：原来所有 AI 请求都从 Cloudflare 服务器转发出去，
Cloudflare 的出口 IP 被上游挡了（`error 1015`，4 毫秒就拒，请求根本没到模型）。

**改法**：浏览器直接请求上游，出口 IP 变成用户自己的网络。

```
之前：浏览器 → Cloudflare Functions → 上游   （死在最后一跳）
现在：浏览器 ─────────────────────→ 上游   （用用户自己的网络）
```

代价是密钥随网页下发。这个工具内部给导购用，属于可接受范围，
所以 `public/config.js` 里放了分段 + base64 的密钥（不是加密，只是不摆在明面上）。

**文件分工**：

| 文件 | 干什么 | 谁生成 |
|---|---|---|
| `lib/` | 业务引擎（零 Node 依赖，Node 和浏览器共用一份） | 手写 |
| `public/lib.bundle.js` | 上面那堆打包成浏览器能跑的一个文件 | `node tools/build_browser.js` |
| `public/config.js` | 上游地址 / 模型名 / 内置密钥 | 手写 |
| `public/bridge.js` | 直连层：节流、静默退避、进度话术、预热 | 手写 |
| `public/app.js` | 界面 | 手写 |
| `functions/api/*` | 后端转发（保留，直连不通时兜底，不再是主路径） | 手写 |

**改了 `lib/` 一定要重新打包**，否则前端用的还是旧引擎：

```bash
node tools/build_browser.js     # 重新生成 public/lib.bundle.js
```

**限速无感化**：上游免费额度约每分钟 15-20 次，撞到了不会让用户看到「限速/重试/失败」，
而是安静地等（6s → 14s → 22s），同时界面接着说真实进度（「正在检查有没有违规说法…」）。
等待过半会换一句（「还在写，快好了…」），超过 30 秒才说「现在用的人有点多」。
话术里每个词都对应引擎里真跑过的一步，不许出现禁用词（`bridge.js` 里有自检）。

## 一、三步跑起来

```bash
# 1. 配置（第一次才需要）
cp .env.example .env
#    打开 .env，把 API_KEY / API_URL / MODEL_NAME 填进去
#    注意：V0.4 之后前端直连用的是 public/config.js，.env 只管后端兜底那条路

# 2. 启动
node server.js
#    Windows 上更省事：直接双击 start.cmd

# 3. 打开
#    电脑：http://localhost:3100
#    手机：http://<电脑的局域网IP>:3100   （同一个 WiFi，启动时控制台会直接打印这个地址）
```

**不需要 `npm install`。** 这个 Demo 只用 Node 内置模块，零第三方依赖 ——
公司电脑上 npm 经常被安全软件拦，零依赖能绕开这一切。Node 18+ 即可（推荐 20/22）。

**没有外网时怎么联调**：本机网络如果拦了上游，可以拿假上游跑通整条链路 ——

```bash
node .tmp/mock_upstream.cjs                                  # 起假上游（127.0.0.1:3999）
DEV_UPSTREAM=http://127.0.0.1:3999/v1 node server.js         # 让页面指向它
```

|---|---|---|

```ini
API_KEY=你在这里填密钥
API_URL=https://api.xxx.com/v1
MODEL_NAME=xxx-flash
PORT=3100
```

改完 `.env` **要重启服务**才生效。
`API_URL` 写 Base URL 就行，代码会自动补 `/chat/completions`。

**怎么确认配置对不对：** 浏览器打开 `http://localhost:3100/api/health`，
只会返回「配置是否完整、用的哪个模型」，**不会返回密钥**。

## 三、这个产品是怎么设计的

### 首页三件套：选行业 / 细分业态 / 店名

- **行业**：17 个（服装 / 餐饮 / 家居 / 家电 / 美业 / 健身 / 母婴 / 宠物 / 汽车服务 / 花艺 / 珠宝首饰 / 手机数码 / 婚纱摄影 / 眼镜 / 家政保洁 / 茶叶 / 其他行业）。
  首页第一屏只放热门 6 个，其余收在「更多行业（11）」里，点开展开；选一次存进浏览器，下次进来直接开始。
  最后一个是「其他行业」兜底包，用通用话术，确保任何门店都不至于卡在选行业这一步。
- **业态**：每个行业下 4 个小标签（如餐饮分正餐 / 快餐小吃 / 奶茶饮品 / 烘焙甜品），**可不选**，选了也记住。
- **店名**：**唯一一个可选输入框**，最长 20 字。不填时文案里一律叫「我们店」；填了也只准原样出现一次，不许据此编「老字号 / 开了十年 / 几家分店」。

这三项都**不算步骤**，7 步向导一步没加。顶部常驻一行显示当前设置，点一下就能改。

> 业态只影响 Prompt 的措辞和示例，**不另做 16 套选项树** —— 4 行业 × 4 业态如果各写一套，维护会崩。
> 选项 id 全行业统一（`boss` / `guide` / `tryon` / `comestore` …），只是中文标签不同，所以前后端不用按行业分叉。

### 交互：7 步向导，全程点选

| 步骤 | 问题 | 选项数 |
|---|---|---|
| 1 | 今天拍什么？ | 11 |
| 2 | 今天主要拍什么？（**跟着第 1 步动态变**） | 每组 7~12 |
| 3 | 这条视频主要想让顾客干什么？ | 10 |
| 4 | 谁来出镜？ | 6 |
| 5 | 想怎么说？ | 12 |
| 6 | 视频多长？ | 3（默认 45 秒） |
| 7 | 还有什么想特别告诉 AI 的？ | 可选，可留空 |

第 2 步不是固定列表 —— 选「新品到店」看到的是连衣裙/外套/针织衫，
选「门店活动」看到的是开业活动/节日活动/换季活动。**用户做选择，AI 负责思考。**

选项定义全部在 `lib/taxonomy.js`，要增删改只改这一个文件，前端不用动。

### 生成：一次只给 1 条，不给你挑花眼

- **视频标题** —— 单独优化，不是照抄第一句话
- **3 秒开头** —— 必须真能说出口，且抓人但不虚假
- **完整口播稿** —— 从头念到尾，照着拍就行
- **一点提醒** —— 只有发现风险才出现（没有就整块隐藏）

生成后可以继续改，**每一个按钮都是真实重新调用大模型**：
换一版 / 开头更抓人 / 更像我说话 / 更接地气 / 短一点 / 复制完整口播 / 重新填写。

### 最重要的一条：不许编造

用户全程只点选，**没有提供任何具体事实**。所以 AI 手上没有价格、面料、款式、活动、销量 ——
这些一个都不许编。内容价值来自**场景、方法、痛点、感受**，不是来自数字。

Prompt 里用三件套把这件事焊死：
1. 高危清单（价格/成分/库存/销量/功效/门店资历/顾客评价……）
2. **真实对照例子**（「用户说 1200 多含羊毛」→ 能怎么说 / 不许变成什么）
3. 兜底话术（「你到店里看一下就知道了」）

实测结论：光列「不许编价格」，模型仍然会飘；**给了对照例子它才真的稳。**

### 另外三条铁律

- **反 AI 腔**：廓形/高级感/氛围感/彰显/轻奢…… 12 个词一个都不许出现，并给出替换说法
- **广告合规**：不许「最/第一/唯一/全网」这类绝对化用语，不许贬低同行、不许虚假紧迫感
- **内部信息保护**：用户在补充框里说的内部价、未公开活动，**不写进口播**，只在提醒区用一句话带过，且不复述敏感内容

## 六、部署到 Cloudflare Pages（配置清单）

仓库：<https://github.com/307816658-eng/shazi-wenan-dashi>

这个项目**同时支持两种运行方式**：本地 `node server.js`（长驻 Node 服务），
以及 Cloudflare Pages（静态文件 + Pages Functions）。两者共用 `lib/core.js`，产品逻辑不重复。

在 Cloudflare Pages 连接 GitHub 仓库时，按下面填（**都是按项目实际情况核对过的，不要改**）：

| 配置项 | 填什么 | 为什么 |
|---|---|---|
| Framework preset | **None** | 原生 HTML/CSS/JS，没有框架 |
| Build command | **留空** | 项目没有 `package.json`、没有构建步骤，填 `npm run build` 必然失败 |
| Build output directory | `public` | 静态页面都在这个目录，直接发布，不需要构建 |
| Root directory | `/`（默认） | `functions/` 必须在仓库根，Pages 才会编译成 Functions |
| Production branch | `main` | Git 主分支 |

**环境变量**（Settings → Variables and Secrets，敏感项选 Secret）：

| 变量名 | 说明 |
|---|---|
| `API_KEY` | 第三方大模型密钥 ← **必须设为 Secret** |
| `API_URL` | OpenAI 兼容 Base URL |
| `MODEL_NAME` | 模型名称 |

变量名以代码实际读取的为准，改名会导致线上跑不起来。`PORT` 在云端用不上，不用配。

**密钥链路**：浏览器 → `/api/generate`（Pages Function）→ 第三方大模型。
前端三个文件里没有任何密钥，`.env` 已被 `.gitignore` 排除、不会随代码上传。

**自动更新**：`git push` 到 `main` 后，Cloudflare 会自动重新构建部署。
本机已配好 Git 凭据，改完代码直接 `git add . && git commit -m "..." && git push` 即可。

### 线上生成的一个外部限制

上游接口对 Cloudflare Workers 的共享出口 IP 有速率限制（`error code: 1015`），
本机直连同一个 Key 正常。这跟代码、Key、部署配置无关。
线上页面、7 步流程、Functions 接口、自动部署都正常；
若生成时撞上限流，页面会显示「这会儿用的人有点多，等几秒再点一次就好」，不会白屏。
要稳定线上生成，换一个不对云主机出口限流的 OpenAI 兼容接口即可
（只改 `API_KEY` / `API_URL` / `MODEL_NAME` 三个环境变量，代码不用动）。

## 七、已知限制（说清楚，不遮掩）

1. **上游有速率限制。** 用的是 Agnes 免费额度接口，连续快速请求会返回 `429`。
   后端已经做了自动重试（等 4 秒、9 秒各试一次），但**短时间内狂点仍可能失败**，
   这时页面会提示「这会儿用的人有点多，等几秒再点一次就好」。
   如果要稳定商用，建议换成付费额度的 key 或提高限额。

2. **上游偶尔很慢。** 实测出现过单次 42 秒。后端超时设 90 秒、前端 120 秒，
   中途不会卡死，但用户可能要等。加载时会显示「通常十几秒，偶尔会慢一点」。

3. **手机访问依赖局域网。** 手机和电脑要在同一个 WiFi；
   Windows 防火墙可能拦 3100 端口；公司网络/安全软件也可能限制局域网互访 ——
   这种情况先在电脑上跑通即可。

4. **首批只做 4 个行业**：服装 / 餐饮 / 家居 / 家电。美业、母婴、宠物、数码等留到下一批。
   **明确不做高监管行业**：医疗、药品、保健品、金融、房产、教育培训 —— 涉及资质和效果承诺，风险太高。

5. **本版本刻意不做**：登录 / 注册 / 会员 / 支付 / 积分 / 数据库 / 后台 / CRM /
   数据分析 / 视频自动生成 / 自动发布抖音。只解决一件事：
   **门店不知道今天拍什么、也不会写口播稿。**

## 八、想改内容 / 加行业？

**改一个行业的说法**：只改 `lib/industries/<行业>.js`（选项、禁编清单、合规红线、AI 腔词表、正反例、内容原料都在里面）。

**加一个新行业**（架构目标：只加 1 个文件 + 1 行注册，前后端和测试都不用改）：
1. 复制 `lib/industries/fashion.js` 成新文件，按同样的字段填内容；
   `topics / second / goals / speakers` 的 **id 必须和其它行业一致**，只改中文标签。
2. 在 `lib/industries/index.js` 里加一行 `require` 和一行 `PACKS` 注册。
   ⚠️ 不能写 `require('./' + id)` —— Workers 打包不支持动态路径。
3. 跑 `node tools/test_industries.js` 验收。

**改通用规矩**（时长、字数、通用广告法、策略生成器）：改 `lib/base.js`。
